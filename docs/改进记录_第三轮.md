# 第三轮改进记录（2026-11-12）

> 依据：`Recording_card/docs/工具改进建议_第二轮_增量.md` §9–§10（币种调用分离）+ 用户补充「SMT 实际 CNY 计价、经济型/标准型必须分开」。
> 验收：`node poc/validate.mjs`（177 项）、`node poc/test-round3.mjs`（联网 OK）。

## 1. USD / CNY 调用分离

- 新增 `include_usd`（默认 true）：`false` 时删除所有 `price_usd`/USD 合计/成本表/`$` 建议文本，只输出 CNY（验收：render 无 `$`）。
- `include_cny=false`：不触发 Chrome，不输出真实 CNY 行/合计（保留明确标注的 estimate）。
- 输出新增 `currency`、`currency_info.price_columns`、独立 `totals` 块：
  - `smt_total_usd` / `smt_per_board_usd`（USD）
  - `retail_total_cny` / `retail_per_board_cny`（立创零售 CNY）
  - `smt_total_cny` / `smt_per_board_cny`（嘉立创国内 SMT CNY）
  - `totals.per_board.{usd,cny_retail,cny_smt}`；USD/CNY 永不混算。

## 2. 嘉立创国内 SMT 人民币实际计价（cny_jlc_cn）

新增 `smt_cost_basis: usd_jlc_global | cny_retail | cny_jlc_cn`；当 `cny_jlc_cn`：

| 项目 | 经济型 economic | 标准型 standard |
|---|---:|---:|
| 工程费 | ¥50/单（单面） | ¥150/面 |
| 钢网费 | ¥0 | ¥50/面 |
| 扩展库上料费 | ¥20/种（封顶 ¥800/单） | ¥8/种（封顶 ¥800/单） |
| 机贴焊点费 | ¥0.01/点 | 0–5万 ¥0.01/点；5–10万 ¥0.008/点；>10万 ¥0.007/点 |
| 器件费 | 立创商城 1pc 人民币价 | 同左 |
| 贴装面 | 仅单面 | 1–2 面 |

- 费率来源：嘉立创官方「贴片、插件焊接收费模式」表（`server_guide_4025.html`，2026-09 更新）。
- **必须显式传 `smt_service_type`**：不传则返回 error，绝不把经济型价格给标准型；`economic + smt_sides=2` 直接拒绝。
- 输出 `cn_smt` 明细：`components_cny / extended_fee_cny / engineering_fee_cny / stencil_fee_cny / joint_fee_cny / total_cny / per_board_cny / joint_count / joint_count_estimated / warnings`。
- `smt_joint_count` 可传整单实际焊点数；不传按封装估算（R/C/二极管 2、三极管 3、IC 引脚数从属性/封装推断），并标 `joint_count_estimated=true`。
- 经济型限制提醒：单面、片式≥0402、IC pin 间距≥0.4mm、BGA 球径≥0.5mm；插件只给提醒，不替用户判断。

## 3. 实测（BOM v0.6，100 片，25 smt / 1 hand / 6 dnp）

| 口径 | 金额 | 每片 |
|---|---:|---:|
| USD（JLCPCB 海外） | $144.69 | $1.4469 |
| CNY 零售（立创，32 行真实价） | ¥399.1/单 | ¥3.991 |
| **CNY SMT 经济型** | **¥904.1/单** | **¥9.041** |
| **CNY SMT 标准型** | **¥910.1/单** | **¥9.101** |

明细（标准型）：元件 ¥399.1 + 上料 ¥96（12 种×¥8）+ 工程 ¥150 + 钢网 ¥50 + 焊点 ¥215（21,500 点估算）= ¥910.1。

## 4. 未做/边界

- 插件工程费（¥20）、AOI、X-RAY、大板费（>650cm² ¥350/单）、包装/治具、整盘预订/现货上料优惠（¥5/种）未计入 —— 这些依赖实际工艺/板面信息，硬编码会误导。
- 器件费按立创 **1pc** 零售价；嘉立创系统按采购量计价，可能更低；最终以嘉立创系统报价为准。
- 经济型/标准型的工艺适配性无法由插件判断，必须人工确认或选标准型。
