## 三、明确未做

- **region=cn 的人民币费率表**：国内嘉立创 SMT 费率需官方计价页确认；`region` 目前只作为口径标签，费用仍按 USD 上料费估算并显式标注假设。
- **命令行 `--json/--bom-out`**：本实现是 DSH 工具（结构化 JSON 即输出），没有独立 CLI；BOM CSV 由 `export_bom=true` 返回。
- **批量 CDP 多标签并发**：当前 Chrome 每次渲染一个页面（并发 2 + 24h 缓存）；28 个料首次全量约 1.5~2 分钟，缓存命中 0s，满足复核场景。

## 四、速度与准确性（2026-11-11 实测）

- **速度**：CNY 链路从「每料一次 Chrome 冷启动（~8-15s）」改为**常驻 Chrome + CDP pipe 多标签**：
  - 冷启动/首屏（执行 WAF 挑战）~5s；之后每料 ~1-2.3s；4-8 标签并发；
  - 28 料完整手焊 BOM：**全新缓存首次 26.5s**、缓存命中 **0.0s/次**；
  - 单条 find 带真实 CNY：缓存命中 ~1-5s；
  - Chrome 空闲 120s 自动退出；插件卸载时 `dispose()`。
- **准确性**（对照 `Recording_card/data/bom_cn_verified_20261111.csv` 与官方口径）：
  - 单料：C1581 ¥0.0239、C7434398 ¥1.097、C307331 ¥0.0251；
  - BOM 层：28 料手焊总价 **¥4.0791**，Recording_card 官方**¥4.0793**（差 ¥0.0002）；
  - 价格：28/28 成功，25/28 与今早快照逐位一致，其余为当日真实价格波动（如 C25741 ¥0.0037→¥0.0036）；
  - 库存：**实时快照**，会随下单变化（C25744 今早 177000 → 现在 22、C668215 89430 → 88000），说明取的是活数据而非缓存旧值（24h 缓存仅用于性能）。

## 五、缓存与垃圾管理（2026-11-11 补充）

- **JSON 结果缓存**：24h TTL，最多 800 条（`cnCacheMaxEntries`），首次查询每小时/每 50 次懒清理，过期/损坏/超量自动删除。
- **Chrome profile**：
  - 启动前与关闭后清理 `Default/Cache`、`Code Cache`、`GPUCache`、`Dawn*`、`ShaderCache`、`Service Worker`、`Crashpad`、`BrowserMetrics`、`component_crx_cache` 等纯缓存目录；
  - 保留 Cookies（WAF 挑战复用，避免每次冷启动）；
  - Chrome 参数硬上限：`--disk-cache-size=50MB`、`--media-cache-size=10MB`；
  - 浏览器空闲 120s 自动退出，插件卸载时 `dispose()`。
- 实测：单次查询后 profile 运行时 2.6MB → dispose 后 **1.3MB**；缓存/Code Cache/Crashpad 全部删除、Cookies 保留、无 Chrome 残留进程。
