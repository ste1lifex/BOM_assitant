# 按立创商城编号下载数据手册：调研与实现（0.4.0）

> 目标：给一个 LCSC 编号（如 `C1581`）和一个目标目录，拿到**官方数据手册 PDF** 落盘，
> 返回绝对路径 / 大小 / SHA-256，而不是把 PDF 内容塞进模型上下文。

## 1. 调研：一个编号可能对应哪几种 PDF 链接

用插件已有的 `getPart()` 对 34 个真实 BOM 料号做了调查，`datasheetUrl` 覆盖率 **34/34**，但 URL 形态有 5 种：

| 形态 | 例子 | 直接 GET 返回 |
|---|---|---|
| 查看器页 | `https://www.lcsc.com/datasheet/lcsc_datasheet_2304140030_FH--..._C1581.pdf` | `text/html`（Next.js 页面，**不是 PDF**） |
| 跳转脚本 | `https://wmsc.lcsc.com/wmsc/upload/file/pdf/v2/lcsc/2306281529_JieLi-Tech-AD142A4_C7434398.pdf` | 142 B 的 `<script>window.top.location.href='…'</script>` |
| 直链 CDN | `https://datasheet.lcsc.com/datasheet/pdf/<hash>.pdf?productCode=C190071` | `application/pdf` ✅ |
| JLCPCB 文件接口 | `https://jlcpcb.com/api/file/downloadByFileSystemAccessId/8588920841703079936` | `application/json`：`{"code":203,"message":"Non-Authoritative Information"}` ❌（链接失效） |
| 国内站 ata | `https://atta.szlcsc.com/upload/public/pdf/source/20260730/<hash>.pdf` | `application/pdf` ✅ |

进一步验证：

1. **查看器页里藏着真 PDF**：`__NEXT_DATA__.props.pageProps.previewPdfUrl`
   = `https://datasheet.lcsc.com/datasheet/pdf/<hash>.pdf?productCode=C1581`，
   同时页面里还有 `pdf.js viewer.html?file=<urlencoded>` 的兜底形态。
2. **跳转脚本里的目标** 同样是 `datasheet.lcsc.com` 直链。
3. **商品页是更稳的入口**：`https://www.lcsc.com/product-detail/<code>.html` 的
   `__NEXT_DATA__.props.pageProps.webData.pdfUrl` 直接就是 `datasheet.lcsc.com` 直链。
   对 `C2765186`（JLCPCB 链接已失效）就是靠这一步救回来的。
4. **国内站**：`item.szlcsc.com/<productId>.html` 页面里嵌了
   `atta.szlcsc.com/upload/public/pdf/source/<日期>/<hash>.pdf`。
   注意 URL 里的 `<productId>` 不是 C 编号（C1581 → productId 1933），
   插件用 `cn.js` 已有的 EasyEDA/lceda `resolvePid()` 映射。
   普通 HTTP 实测直接能拿到页面（141 KB），WAF 阵发时才需要无头 Chrome。
5. **EasyEDA 商品 API**（`easyeda.com/api/products/<code>/components`）在本机被 CloudFront 403，
   不作为手册来源，只用于解析国内站 productId。

## 2. 解析与兜底流程

```
LCSC 编号
  ├─ service.part() 拿 identity + datasheetUrl（JLC 记录）
  ├─ service.productPage() 拿 webData.pdfUrl（商品页，服务内已有 TTL 缓存）
  ├─ 候选 1：part.datasheetUrl
  ├─ 候选 2：商品页 pdfUrl
  │    └─ 每个候选：fetch → 看字节
  │         ├─ %PDF- 开头 → 收下
  │         └─ HTML/JS → 抽下一跳（最多 3 跳）：
  │              previewPdfUrl | datasheet/atta CDN 链接 | location.href
  │              | meta refresh | pdf.js viewer?file= | pdfUrl | 任意 .pdf
  └─ 候选 3（前两个都失败才走）：国内站
       resolvePid() → item.szlcsc.com/<pid>.html → atta PDF
       普通 HTTP 优先；WAF 挑战才 renderHtml()（无头 Chrome，可关）
```

关键设计：**不按 URL 形态猜，而是 fetch 后看字节**。这样新增一种包装页（或 CDN 换域名）
只影响抽取规则，不会把工具写死在一份 URL 模板上。所有候选失败时返回 `not-found` + 商品页链接，
绝不拼接一个未经验证的 PDF URL。

## 3. 工具设计

工具名：`download_lcsc_datasheet`（Host-only，与现有 2 个工具同一插件）。

| 参数 | 必填 | 说明 |
|---|---|---|
| `lcsc` | ✔ | LCSC 编号，大小写不敏感，`1581` 会归一化为 `C1581` |
| `out_dir` | ✔ | 目标目录；递归创建；`~` 展开；相对路径按 DSH 会话工作目录解析 |
| `filename` | | 只接受文件名，不允许目录分隔符；缺 `.pdf` 自动补 |
| `overwrite` | | 默认 false → 已存在时返回 `already-exists`，不重复下载 |
| `domestic_fallback` | | 默认 true；false 时跳过立创国内站兜底（更快） |

输出（`additionalProperties: false` 的 JSON schema）：
`status`、`lcsc`、`model`、`brand`、`package`、`out_dir`、`file_path`、`file_name`、`bytes`、
`sha256`、`content_type`、`source`、`pdf_url`、`datasheet_url`、`datasheet_page`、`resolved_via`、
`attempts`、`notes`、`hints`、`fetched_at`。

安全/健壮性：

- 文件名清洗 Windows 非法字符、保留名（CON/PRN/…）、结尾点/空格，限长 120；
- 拒绝 `../x.pdf`、`a/b.pdf` 一类路径穿越；
- 先写同目录临时文件再 rename（原子落盘），`overwrite` 时先删旧文件；
- 单文件默认 64 MB 上限（内容长度 + 流式累计双重检查）；
- 只接受 `%PDF-` 字节；HTML/JSON 一律视为失败候选；
- 超时 / 取消都转成失败结果（取消会向上传播）。
- 工具声明 `timeoutMs: 180000`，并全程把 `exec.signal` 传给 fetch。

## 4. 实测（2026-11-15）

| 编号 | 路径 | 结果 | 耗时 |
|---|---|---|---|
| `C1581` | 查看器页 → `previewPdfUrl` → CDN | 3,187,974 B，`%PDF-` ✅ | 5.1 s（含 part + 商品页 + 查看器） |
| `C7434398` | `wmsc` 跳转 → CDN | 996,299 B ✅ | 3.0 s |
| `C2765186` | JLCPCB 接口 203 → 商品页 `pdfUrl` | 1,584,275 B ✅ | 1.6 s |
| `C1581`（强制国内站） | `item.szlcsc.com/1933.html` → atta | 3,187,974 B ✅ | — |
| `C1`（非法编号） | — | `not-found` + 提示 ✅ | < 10 ms |

## 6. 边界

- 只下载公开可达的官方 PDF；没有公开手册的料号（部分连接器/结构件/定制料）返回 `not-found`。
- `jlcpcb.com/api/file/...` 链接会失效；插件靠商品页兜底，商品页也没有就失败。
- 国内站 `productId` 依赖 EasyEDA/lceda 数据；新料/非零售料可能查不到，重试无用。
- 手册是抓取时刻的版本；原厂改版后需要重新下载。
- 不做 OCR/解析内容，PDF 读取请交给 `dsh-pdf-reader` 之类的工具。
