## 2. 具体改动

### 2.1 exact 模式（`need="C..."` 或 `codes=[...]`）

- 走 `service.part()`（JLC + 立创商品页），不再依赖 `searchRaw` 的模糊结果；最多 20 个编号，并发 3。
- 每行字段：`lcsc`、`status`、`model/brand/package/category`、`library`、`stock_smt/stock_retail/stock_available`、`price_usd/price_cny`、`attributes`、`size`、`datasheet_url`、`product_url`、`data_warnings`。
- `status` 按请求的 `assembly` 渠道判定（hand 看零售、smt 看 SMT 库）：`stock_available` 是保守最小值，不能直接拿来判 status，否则“零售 0 / SMT 有货”会被误报为缺货。
- `stock_retail_source` 标明零售库存来自 `item.szlcsc.com`（cn）还是 `lcsc.com`（intl）；渲染为 `retail 116(cn)` / `retail 116(intl)`。
- 顶部 `exact_summary` 汇总各状态数量；`unknown_code` 明确提示“格式/编号核对”，`out_of_stock` 提示用型号 + `exclude_lcsc` 找替代。
- CNY 实时取价最多覆盖前 8 个编号（避免 20 次 Chrome）；超过时其余为标注 `estimated=true` 的估算。

### 2.2 品类浏览（`category`）

```jsonc
{"category":"buzzer",
 "filters":{"Technology":"Piezoelectric","Driver Circuitry":"Passive","Mounting Type":"SMD"},
 "sort":"size","limit":10,"max_scan":5000}
```

- 分页：`pageSize=1000`、`currentPage` 最多 50。实测公开接口接受 1000/页（旧服务层钳在 100/页、10 页，是本次放开的）；4605 条蜂鸣器 = 5 次请求。
- `filters`：上游属性名、大小写不敏感、等值或包含；属性值为 `-` 时回退到封装/描述文本（所以 `Mounting Type=SMD` 能匹配 `package="SMD,5x5mm"`）。
- `filter_report`：每个 filter 的 `matched_count` + 实际出现的值（最多 8 个），不匹配时直接告诉 agent 怎么改，不用再探接口。
- `sort="size"`：解析 `Length/Width/Height` 或 `Diameter(φD)`，也回退解析 `SMD,5x5mm` 这类封装；面积升序，无尺寸排最后；次级按库存/价格。
- 返回 `browse`：`category / scanned / total / truncated / matched / filters / sort`；截断时提示提高 `max_scan`。

### 2.3 自然语言里的蜂鸣器属性

- 需求里出现“无源/压电/贴片/有源/电磁/插件”时，转成 `Technology / Driver Circuitry / Mounting Type` 属性条件；仅在蜂鸣器/扬声器/麦克风语境生效，避免把“贴片”当成所有元件的硬过滤。
- 这样 `need="无源压电贴片蜂鸣器"` 不会再把有源电磁插件蜂鸣器当成同品类候选；若该品类只有不匹配的料，返回 0 条并提示“没有同时满足 …”。

### 2.4 不跨品类降级

- 阶段 1/2 仍然只在原品类内放宽参数；阶段 3 必须通过 `candidateMatchesCategory()`，否则：
  - 候选 0 条；
  - hint 明确“JLC SMT 库里没有「buzzer」品类的在库料……不要继续穷举立创接口”；
  - 不再返回“最接近”的其它品类。

### 2.5 描述与渲染

- `find_lcsc_parts` description 重写：数据源边界、三种模式、filters/size、状态含义、不要裸探接口。
- `renderFindText` 增加：`status` 标签、尺寸、属性行、`ds/product` 链接、`filter_report`、exact 汇总、browse 扫描信息。模型看到的是渲染文本，属性必须进渲染才有用。

## 3. 实测（2026-11-24）

| 场景 | 结果 |
|---|---|
| `need="C22359711"` | 1 行，`status=out_of_stock`，`CSS-0575A-SMT-TR`，5×5×2mm，15 个属性，datasheet/product 链接齐全 |
| `codes=["C22359711","C20181991","C999999999"]` | `ok=1 / out_of_stock=1 / unknown_code=1`，3 行一次返回 |
| `need="无源压电蜂鸣器 贴片 3.3V"` | 5 条真实蜂鸣器（GMC/SMD 系列），不再出现 RF 模组 |
| `need="无源压电贴片蜂鸣器 3.3V 尺寸尽量小"` | 属性词（无源/压电/贴片）转成 `Technology=Piezoelectric / Driver=Passive / Mounting=SMD` 过滤，返回 5 条压电无源候选；有源电磁插件蜂鸣器被排除，并提示用 `sort="size"` 或 category 浏览找全品类最小 |
| `category="buzzer" + 3 filters + sort=size + max_scan=5000` | 扫描 4605/4605，matched=39，最小 7.5×7.5×2mm、Ø10×2.5mm…，每条带属性/链接；`filter_report` 给出 Technology/Driver/Mounting 的实际值 |
| 无匹配 filter（`Technology=Electret`） | 0 条 + `filter_report` + “按 filter_report 调整”的 hint |

## 5. 已知边界

- 品类浏览首次扫描大品类 6–10s；10min 缓存内重复查询秒回。
- `sort=size` 依赖上游尺寸字段；解析不到的料排最后并标 `has_size=false`。
- 检索仍只覆盖 JLCPCB SMT 库；零售专属料需用已知编号查。
- 同型号多编号、alternatives_of、24h 品类缓存未做（理由见第 1 节）。
